# 코팅 초기조건 도출 과제만 실행할 때 쓰는 최소 설치 세트.
#
#   python -m pip install -r requirements-coating.txt
#
# 왜 pyproject 가 아니라 별도 파일인가:
# pyproject 의 base dependencies(fastapi / uvicorn / langgraph / langchain-* /

# 그런데 pip 의 extras 는 base 를 항상 함께 깐다 - `pip install -e ".[ml]"` 로는
# 그 20여 개를 뺄 수 없다. 사내 폐쇄망/프록시에서는 받아야 할 패키지 수가 곧
# 실패 확률이라, 코팅이 실제로 import 하는 것만 여기 고정한다.
#
# 이 파일로 설치하면 `pip install -e .` 는 하지 않는다. backend/ 에서
# `python -m app.coating.report` 로 실행하면 cwd 가 sys.path 에 들어가 app 을 찾는다.
#
# 전체 앱(채팅 + 금형 + 코팅)까지 필요하면 대신:  pip install -e ".[all]"
#
# 버전 하한은 pyproject 의 optional-dependencies.ml 과 일치시킨다. 한쪽만 올리지 않는다.
